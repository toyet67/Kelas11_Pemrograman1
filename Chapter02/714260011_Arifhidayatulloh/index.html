Alur Kerja Client-Server

  1. Pengguna mengetik alamat situs di browser.
  2. Browser mencari server yang menyimpan situs itu.
  3. Browser mengirim request untuk meminta halaman.
  4. Server mengirim response berisi file HTML.
  5. Browser membaca HTML itu dan menampilkan halamannya.
